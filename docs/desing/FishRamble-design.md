# FishRamble!! — ゲーム概要

## ゲームの一言説明

> スマホをコントローラーにして、カヤックで戦う 6人対戦アクションゲーム。
> 釣った魚を振り回して相手チームを攻撃しろ。

---

## 基本情報

| 項目 | 内容 |
|------|------|
| プラットフォーム | Unity（PC/大画面表示） + スマホ（コントローラー） |
| 対戦形式 | 2チーム × 3人 = 計6人同時プレイ |
| 接続方法 | スマホでQRコードをスキャン → Unityクライアントに接続 |
| 勝利条件 | 相手チームの全員HPを0にしたチームの勝ち |

---

## チーム構成と役割

各チーム3人で以下の役割を分担する。

| 役割 | 操作方法 | 使用センサー |
|------|---------|------------|
| 右オール | スマホを振る → カヤックを右で漕ぐ | 加速度センサー |
| 左オール | スマホを振る → カヤックを左で漕ぐ | 加速度センサー |
| 釣り担当 | スマホを構えて方角で狙い、振りかぶって投げる | 方位磁針 + 加速度センサー |

---

## 魚アイテムの種類（予定）

| 種類 | 効果 |
|------|------|
| 通常の魚 | 当てると10ダメージ |
| 速度バフ系の魚 | 命中で相手カヤックを急加速・弾き飛ばす |
| 大型の魚 | 当たり判定大・高ダメージ |

※ 魚の種類はランダムまたは釣った位置で決まる予定。釣った魚は原則強制使用（任意で捨てることも可）。

---

## ビジュアルのキーワード

- **舞台:** 海上（水面 + 波のシェーダー予定）
- **キャラクター:** カヤックに乗ったラグドール人形（**TABS風のぷらんぷらん物理挙動**が常時適用）
- **カヤック:** オールで漕いで進む。進行方向はオールのみで操作可能
- **釣り竿:** 船の前方向き・左右斜め45度の範囲で可動
